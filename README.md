# ClutchIQ — Website Prototype

A responsive, static landing-page prototype for ClutchIQ, a proposed VALORANT performance review companion.

## Run it on Windows 11

1. Download and extract `ClutchIQ.zip`.
2. Open the extracted `ClutchIQ` folder.
3. Double-click `index.html`.
4. It should open in your default browser. No Node.js, editor, or installation is required to preview this first prototype.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `app.js` — mobile navigation and demo waitlist interaction

## Important prototype limitations

- The dashboard uses fictional sample data for visual demonstration.
- The waitlist form saves entries only in the current browser's local storage. It does not send data to a server or create a real mailing list.
- There is no login, database, payment system, AI analysis, Riot API integration, or Windows installer yet.
- No Riot game files, process memory, or live game state are accessed.
- The product is an independent concept and is not affiliated with or endorsed by Riot Games.
